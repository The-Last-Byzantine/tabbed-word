# TabbedWord 2026.11.53

Deploy the contents of this folder to your static host.

The document stays in a centered column between symmetric left and right shoulders. Each shoulder has its own show/hide control at its upper-right. Both contents start collapsed; controls and shoulder space remain. Showing either side does not shift the document.

AI integrations have been removed. Command search, writing statistics, comments, tracked changes, references, exports, versions, local drafts, Organizer and Google Drive tools are retained.

## What's new in 2026.11.53

- Shoulders: Tabs (left) and Tools (right) are visible by default; each has its hide button at its outer upper corner.
- Status bar: Focus, Print layout and Web layout buttons, and a zoom slider from 50% to 200%.
- Font and size pickers in the Font group, applied per paragraph. Times New Roman 12 pt remains the default.
- Open-source fonts: Source Serif 4, Source Sans 3, Inter and JetBrains Mono (OFL 1.1), alongside Literata.
- Ribbon colours and typography follow WordCraft's interface; credits and licence notices are in the About dialog and third-party-licenses.txt.
